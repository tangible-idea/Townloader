# 다운로드 권한 자료 조사

확인일: 2026-10-01

공개된 공식 자료에서 Townloader의 현재 Instagram·Threads 다운로드 기능을 명시적으로 허가하는 문서는 찾지 못했습니다. 아래 문서는 관련 조건을 설명하는 자료이며, Townloader에 발급된 허가서가 아닙니다.

| 공식 자료 | 확인한 내용 | 심사 자료로서의 한계 |
| --- | --- | --- |
| [HikerAPI 이용약관, C항](https://hikerapi.com/help/terms-of-service) | 사이트/서비스와 관련한 개인적·비상업적 접근·표시·복사 라이선스를 설명합니다. | 공개 iOS 다운로드 앱에 적용되는 서비스·콘텐츠 권한을 이 조항만으로 확인할 수 없습니다. Meta의 허가서도 확인되지 않았습니다. |
| [Meta 공식 자동 수집 안내](https://about.fb.com/news/2021/04/how-we-combat-scraping/) | 사전 허가 없는 자동 수집을 제한한다고 설명합니다. | 2021년 설명 자료이며, 다운로드를 허가하는 문서가 아닙니다. |
| [Apple 심사 지침 5.2.2–5.2.3](https://developer.apple.com/app-store/review/guidelines/#intellectual-property) | 외부 서비스 이용 및 미디어 다운로드에 대한 허가 자료를 요청할 수 있다고 명시합니다. | 개인 보관 목적이나 공개 게시물이라는 설명만으로 허가가 입증되지는 않습니다. |

Instagram/Threads의 약관 페이지와 Meta 자동 수집 약관 원문은 이번 조회에서 로그인 요구 또는 로딩 오류로 내용을 직접 확인하지 못했습니다. 공개 API 문서나 미디어 URL의 존재도 현재 앱에 발급된 허가의 증거로 취급하지 않았습니다.

확보할 자료는 Townloader의 사용 범위를 명시한 제공업체의 계약·허가 확인서, 필요한 서비스 측 허가, 그리고 해당 콘텐츠의 소유권 또는 이용 허락입니다. 실제로 어떤 자료가 존재하고 어떤 범위를 허용하는지는 발급 주체에 확인해야 합니다.

HikerAPI 문의처는 공식 [연락처 문서](https://hiker-doc.readthedocs.io/en/latest/support/contacts/)에 있는 support@hikerapi.com입니다. 아래 문의 초안은 전송하지 않았습니다. HikerAPI 관련 자료를 확보해도 별도로 처리하는 Threads 기능의 허가가 입증되지는 않습니다.

## HikerAPI 문의 초안

To: support@hikerapi.com

Subject: Authorization documentation for Townloader iOS App Review

Hello HikerAPI team,

Townloader (net.tangibleidea.townloader) is an iOS app that uses HikerAPI to retrieve public Instagram post metadata and media URLs, then lets users save the media to their devices.

Apple has requested authorization documentation. Could you provide:

1. Written terms or a contract permitting this use in a publicly distributed iOS app.
2. Any underlying Meta/Instagram authorization and whether it covers our app's display and download functionality.
3. The scope of any content permissions, including creator consent requirements and restrictions.

If these permissions are not provided by your service, please confirm that explicitly.

Thank you,
Mark
