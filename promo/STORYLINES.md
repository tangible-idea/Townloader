# Townloader 홍보영상 스토리라인

조건: 약 30초, 9:16(1080x1920), 한국어, 음성 없음(자막형 문구 + 음악·효과음), 다른 사람의 사진과 계정명은 가림.
근거: README.md, store/, lib/l10n/strings.dart, lib/ui/ 소스. 숫자는 실제 앱 데이터(글 4개, 장소 107곳)만 사용.

## A. 링크 한 줄, 장소 107곳 (추천)
- 장치·형식: 숫자가 착지 + 앞 화면의 물건이 다음 화면을 여는 연쇄.
- 내용: 저장만 해 둔 맛집·여행 글이 쌓여 있다. 링크 하나가 장소 칩으로 터지고, 칩이 지도 위 말풍선이 되어 "장소 107곳"에 착지한다.
- 첫 2초: 첫 프레임부터 큰 문구 "저장만 하고 못 간 곳". 실제 링크 카드 목록이 빠르게 쌓인다.
- 흐름: 훅 → 쌓인 글 → 링크 붙여넣기 → 쉬머 → 장소 칩 → 지도 비행과 107곳 → 카드 넘기기 → 장소 상세·후기 → 스레드 읽기와 AI 요약 → 원본 저장 → 지도 링크 공유 → 엔드 카드.
- 룩: 앱의 흰 바탕과 검정 버튼, 포인트는 지도 핀의 초록·주황. 지도가 화면을 채우는 세계와 흰 앱 화면이 번갈아 나온다.
- 소리: 경쾌한 비트에 맞춘 컷, 칩과 핀이 나올 때 짧은 톡 소리.

## B. 금요일 밤에 저장, 토요일 아침에 출발
- 장치·형식: 하루의 한 순간 + 시간 표시로 나뉜 컷.
- 내용: 금요일 밤 침대에서 단풍 글을 발견하고, 토요일 아침에 지도를 열어 친구에게 링크를 보낸다.
- 첫 2초: "금 23:40" 표시와 "이번 주말 어디 가지?". 공유 시트에서 Townloader를 고른다.
- 흐름: 금요일 밤 → 공유로 저장 → 장소 칩 → 토요일 아침 지도 → 상세·후기 → 친구에게 지도 링크 → 스레드와 AI 요약 → 저장 → 엔드 카드.
- 룩: 밤은 다크 모드, 아침은 라이트 모드로 앱의 실제 테마 차이를 쓴다.
- 소리: 잔잔하게 시작해 토요일 아침부터 밝아지는 음악, 알림음 하나.

## C. 지구본에서 내 저장 글까지 (과감한 안)
- 장치·형식: 앱 지도 자체가 설명 + 끝없는 줌 한 호흡.
- 내용: 앱의 실제 지구본에서 시작해 한국으로 내려가고, 말풍선 카드 안으로 들어가면 글이, 글 안으로 들어가면 스레드와 요약이 나온다. 마지막에 다시 지구본까지 빠져나온다.
- 첫 2초: 하늘색 배경의 실제 지구본 위 "내가 저장한 곳들". 바로 하강이 시작된다.
- 흐름: 지구본 → 하강과 107곳 → 말풍선 → 장소 상세 → 원문 글 → 스레드·AI 요약 → 저장 → 공유 링크 → 지구본으로 복귀와 엔드 카드.
- 룩: 지도가 무대. 앱의 하늘색 지구본, 흰 말풍선, 컷 없는 연결.
- 소리: 하강하는 동안 음이 쌓이다가 착지마다 터지는 구성.
